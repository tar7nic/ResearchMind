# ResearchMind 🔬

An agentic research assistant that autonomously searches the web, executes code, reads documents,
synthesizes findings into a structured report, and self-evaluates its output using an LLM-as-judge rubric.

> **Note:** Image input is not functional in the current version due to vision API limitations on free tier keys. PDF text extraction and all text-based queries are fully functional.

---

## Live Demo

🚀 [researchmind-tn019.streamlit.app](https://researchmind-tn019.streamlit.app)

---

## Architecture

```
User Input (text + optional PDF)
        ↓
  Input Parser (unified_context.py)
        ↓
  LangGraph Agent
  ├── Supervisor Node      — tool routing and reasoning
  ├── Tool Executor Node   — Tavily search, Python REPL, PDF reader
  ├── Synthesis Node       — structured markdown report with citations
  ├── Judge Node           — LLM-as-judge scorecard (4 dimensions)
  └── Storage Node         — SQLite persistence
        ↓
  Streamlit UI (4 pages)
  ├── Research Query       — query input + file upload
  ├── Agent Trace          — step-by-step tool call viewer
  ├── Report Output        — rendered markdown + PDF download
  └── Evaluation Scorecard — radar chart + session history
```

## Setup

### 1. Clone the repo

```bash
git clone https://github.com/yourusername/ResearchMind.git
cd ResearchMind
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

```bash
cp .env.example .env
# Add your GROQ_API_KEY and TAVILY_API_KEY to .env
```

Get your free API keys here:
- Groq — [console.groq.com](https://console.groq.com)
- Tavily — [app.tavily.com](https://app.tavily.com)

### 5. Run the app

```bash
streamlit run app.py
```

## Known Limitations

- Image input (direct image uploads) is currently disabled due to vision API limitations on free tier keys
- PDF image extraction is parsed but not passed to the LLM in the current free tier configuration
- Groq free tier has rate limits — if you hit a 429, wait 30 seconds and retry
